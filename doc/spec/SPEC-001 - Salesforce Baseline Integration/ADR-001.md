# SPEC-001: ADR-001 - Selection of simple-salesforce & python-dotenv

- **Specification ID**: SPEC-001
- **ADR ID**: ADR-001
- **Status**: Accepted
- **Deciders**: Engineering Team
- **Date**: 2026-10-27

---

## 1. Context and Problem Statement

SPEC-001 requires authenticating against Salesforce REST APIs, handling SOQL query pagination, and managing credentials securely without hardcoding secrets in source control.

---

## 2. Decision Outcome

Chosen Option: **`simple-salesforce` + `python-dotenv`**

### Positive Consequences
- Automatic handling of OAuth / SOAP session creation and instance URL resolution.
- Native `query_all` for handling > 2,000 SOQL query records transparently.
- Built-in support for Bulk API 2.0.
- Clean separation of `.env` local development credentials from cloud runtime variables.

### Negative Consequences
- Synchronous I/O: high-volume concurrent queries require thread pooling or process workers.
